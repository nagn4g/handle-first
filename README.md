A short poem about permission: a mother's scissors, handle first, and the next cut mine.

> I asked my mother for the scissors. She put them in my hand, handle first, and said, cut. I took one lock of my own hair at the temple and let it fall — and the floor caught it like a small dark permission, and I knew the next cut would be mine.

The speaker asks for the scissors, is given them handle first, cuts one lock, and knows the next cut will be theirs.

The poem contains 245 Unicode code points and 247 UTF-8 bytes; the program writes it to `/output/entry.txt` without a trailing newline.
